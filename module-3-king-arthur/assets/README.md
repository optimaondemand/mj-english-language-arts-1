# Assets — Module 3 (King Arthur)

This module's lesson pages reference **no local image files.** They are text-and-card lessons. The
anchor text (Roger Lancelyn Green's *King Arthur and His Knights*) is **not public domain** — students
read from their own lawful copy. Per Optima ELA copyright policy, **no PDF or ebook of the novel is ever
hosted or linked in Canvas Files**; the novel is taught *about*, with original instruction and only
brief fair-use excerpts on lesson pages.

If a future revision adds illustrative images (e.g., a knight comparison-chart template or a gallery layout
diagram), place them here and reference them from the lesson pages. Per the Optima visuals convention,
prefer inline HTML/CSS mockups (already used throughout the lesson pages) over AI-generated images.
